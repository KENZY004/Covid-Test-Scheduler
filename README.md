# 🧪 Health Scheduler — Priority-Based Appointment System (DSA Project)

Health Scheduler is a frontend-focused web application built during summer training to demonstrate the **practical application of Data Structures and Algorithms (DSA)** in a real-world healthcare scenario.

The project simulates a COVID-19 testing and vaccination appointment system where patients are scheduled using **priority-based logic**, ensuring high-risk cases are handled first.

---

## 🎯 Project Objective
- Apply core **DSA concepts** in a realistic use case
- Design a **priority-driven scheduling system**
- Translate algorithmic logic into interactive UI behavior

---

## ✨ Key Features
- COVID-19 testing and vaccination appointment booking
- **Priority-based queue management** (High / Medium / Low risk)
- Interactive booking dashboard with queue visualization
- Dynamic time-slot allocation and availability control
- Appointment cancellation with automatic queue updates
- Clean, responsive, healthcare-themed interface

---

## 🧠 Data Structures Used
- **Priority Queue (Min-Heap)**  
  Used to prioritize patients based on risk level

- **Hash Map Logic**  
  Efficient handling of appointment slots and scheduling data

- **Queue Management Algorithms**  
  For estimating wait times and maintaining fairness

> 📌 The primary focus of this project is **DSA implementation**, not backend infrastructure.
